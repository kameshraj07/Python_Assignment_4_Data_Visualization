🚕 Taxi Data Analysis & Visualization
📌 Project Overview
This project focuses on exploratory data analysis and data visualization using Python. The Taxis dataset available through the Seaborn library is used to analyze taxi trips and understand patterns in fares, distances, tips, payment methods, pickup locations, and other numerical and categorical variables.

The project demonstrates practical usage of Pandas, Matplotlib, and Seaborn for cleaning data and creating meaningful visualizations.

🎯 Objectives
The main objectives of this project are:

Load and explore the Seaborn Taxis dataset.
Identify missing values in the dataset.
Handle missing values using appropriate techniques.
Identify numerical and categorical columns.
Analyze taxi fares and trip distances.
Understand the distribution of trips across pickup boroughs.
Analyze payment methods.
Study relationships between distance, fare, tip, and total amount.
Visualize correlations between numerical variables.
Compare fare distributions across payment methods.

🧹 Data Cleaning
Missing values are checked using:

taxis.isnull().sum()
The project demonstrates two approaches for handling missing values.

1. Imputation
For numerical columns, missing values are replaced with the median.

For categorical columns, missing values are replaced with the mode.

for column in numeric_columns:
    taxis[column] = taxis[column].fillna(taxis[column].median())

for col in categorical_columns:
    taxis[col] = taxis[col].fillna(taxis[col].mode()[0])
2. Removing Missing Values
Rows containing missing values in critical columns can also be removed using:

taxis = taxis.dropna(subset=critical_columns)
